Haxora opens HaxBall in a window of its own: higher FPS, less delay, and a pile of things the browser never gave you. No installer, free, and the interface comes in English and Turkish.

## Highlights

| | |
| :-- | :-- |
| ⚡ **High FPS** | Lift the frame rate cap. The game doesn't slow down when it goes to the background. |
| 👥 **Friends and DMs** | See who's online and message them without leaving the match. |
| 💬 **Message notifications** | A message that arrives mid-match shows up in a notification that never covers the pitch. Its position and prominence are up to you. |
| 🔇 **Muting** | Silence the guy getting on your nerves, on your screen only. Works in rooms that relay chat through a bot too. |
| ⚽ **Goal effects** | Scoring and conceding get their own visual effect on the pitch. Pick a different one for each, or turn them off. |
| 🎨 **Themes and looks** | Accent colour, ball skin, scoreboard, key bindings. |
| 📤 **Shareable settings** | Turn your looks and key bindings into a code and send it to a friend. Paste a code you receive and their setup opens on your side. |
| 🎵 **Spotify controls** | Play, pause or skip a track without leaving the match. No alt-tab, no ball lost while you do it. |
| 🎮 **Discord Rich Presence** | While you play, your Discord profile shows that you're on Haxora. |
| 😀 **Avatar reactions** | Bind an emoji to a key; your avatar becomes that emoji while you hold it. |
| 🎯 **Training mode** | Practise shooting and passing on your own. |
| 🎬 **Match recording** | Record a match and watch it back later. |
| ⭐ **Favourite rooms** | The rooms you play in most, plus your room history, always at hand. |

## Install

**1.** Download [`Haxora.exe`](https://github.com/nycr0x/Haxora-haxball-client/releases/latest)
**2.** Double-click it — no setup wizard, no admin rights

**Requires:** Windows 10 or 11, 64-bit

> [!NOTE]
> If Windows says it **"protected your PC"** → **More info** → **Run anyway**.
> The warning appears because the file has no code-signing certificate; every unsigned program gets it, and it doesn't mean anything was found in the file. Certificates cost money, so Haxora ships unsigned for now.

## Is it safe, and what does it keep?

The short answers, and where you can check them:

- **Download it here only.** The [Releases](https://github.com/nycr0x/Haxora-haxball-client/releases) page of this repository is the one official channel. A "Haxora" file on any other site has nothing to do with me.
- **No account required.** You don't need to sign in to join a room and play. An account is only for the friend list, private messages and settings sync.
- **Your settings stay with you.** Themes, key bindings and favourite rooms are stored locally on your machine.
- **Spotify.** You connect through Spotify's own sign-in screen, so Haxora never sees your password; it only handles playback (play / pause / skip).
- **It doesn't touch the game itself.** Haxora is an independent client built on [node-haxball](https://github.com/wxyz-abcd/node-haxball); features like muting apply to your screen only and don't affect other players.

## Changing the language

The interface ships in English and Turkish. Three ways to change it:

- **First run** — the language is the first choice on the welcome screen
- **Main menu** — the `TR` / `EN` pill in the top bar
- **Settings** — *Settings → General → Language*, both in the lobby and during a match

The change applies immediately; nothing needs restarting.
